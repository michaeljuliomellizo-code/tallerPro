MOTOMIL - BATCH DE 40 ARCHIVOS
==============================

Este ZIP contiene 40 archivos funcionales/utilitarios como siguiente lote.
Se apoya únicamente en el esquema confirmado durante la conversación:
organizations, organization_members, customers, motorcycles, mechanics,
service_orders, service_order_items, inventory_products.

Hay rutas auxiliares nuevas para avanzar rápidamente sin alterar necesariamente
la navegación principal. Antes de reemplazar archivos ya modificados, haga copia
de seguridad.

IMPORTANTE:
- El lote no inventa tablas de proveedores, pagos, facturación, citas ni
  inventory_movements.
- No sustituye los componentes de Clientes, Motocicletas ni Órdenes que ya
  fueron validados, salvo las rutas indicadas explícitamente.
- Ejecute después de copiar:
    npm run build
- El build definitivo debe hacerse en C:\Project\motomil-platform.
- Cualquier error de TypeScript debe corregirse antes de seguir.
